# Multi-Actuator Gripper Simulation

Simulation workflows for the multi-actuator soft gripper (BORG Lab, Carnegie Mellon University). Covers fluid-flow pressure analysis (SolidWorks) and structural/FEA analysis (Ansys Discovery → Ansys Mechanical) of the actuator/gripper assembly.

## Overview

This repository contains the CAD geometry, material characterization data, simulation setups, and results used to evaluate actuator deformation and internal pressure behavior under load.
